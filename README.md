# MechanicMatchFL

MechanicMatchFL is a South Florida marketplace for discovering automotive repair and mechanical-maintenance providers, with an emphasis on independent shops, mobile mechanics, tire/service shops, and repair specialists.

## Project status

- M1 Stress Test + Scope Lock: PASS
- Overall completion: 10%
- Current milestone: M2 Provider Data + Matching Logic
- Hosting: Vercel
- Framework: Next.js
- Planned domain: MechanicMatchFL.com

This repository follows the project BUILD OPERATING SYSTEM: scope-locked milestones, focused branches, testing before merge, and no unrelated feature expansion during implementation.
